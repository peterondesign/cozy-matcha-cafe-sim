# New Game Visual Build

This folder contains the rebuilt visual version of Little Matcha Days.

## Structure

- `00-source/`: approved source screens and untouched visual references.
- `01-backgrounds/`: empty daytime and nighttime environment plates.
- `02-cart/`: empty cart, counter, tools, and cart progression layers.
- `03-dialogue/`: transparent speech bubbles and dialogue ornaments.
- `04-orders/`: isolated drink-order images.
- `05-recipe-frames/`: six-frame action sequences for every recipe step.
- `06-layer-decomposition/`: original layer-decomposition outputs.
- `07-sprite-sheets/`: generated 4 by 4 state sheets before extraction.
- `08-final-png/`: cleaned transparent runtime PNG files.
- `09-prompts/`: exact generation prompts and output records.
- `game/`: rebuilt playable screen using approved visual assets.

The approved first-screen reference is `00-source/first-game-screen.webp`.
